# Project visuals

Store project-specific images and supporting files in a folder named for the project's `id` in `assets/js/projects.js`.

For example:

```text
assets/projects/
  stochastic-topology-reliability/
    cover.webp
    reliability-plot.png
```

Set that project's `cover` to `assets/projects/stochastic-topology-reliability/cover.webp` and `coverAlt` to a short, accurate description. If the image is missing, the site displays the built-in abstract visual instead. Use optimized WebP/JPEG for photographs and PNG/SVG for diagrams; avoid including confidential project or employer material.
